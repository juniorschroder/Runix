Recursos Principais

Projetado para Produtividade e Estabilidade

Arquitetura limpa, binários nativos auto-contidos e ferramentas visuais completas para desenvolvedores e DBAs.

🖥️

Multiplataforma Nativo

Executáveis self-contained para macOS (Apple Silicon & Intel), Linux (.deb / .rpm) e Windows (.exe) sem dependência de runtime externo.

📐

Modelagem DER Bidirecional

Visualize chaves estrangeiras no canvas interativo, crie tabelas e colunas visualmente e gere scripts DDL de migração com preview seguro.

🛡️

Resiliência com Vard

Proteção contra falhas transitórias de rede usando Retry com Exponential Backoff e Circuit Breaker sem perder o estado das suas abas.

⚡

Editor SQL Inteligente

Autocomplete contextual de tabelas e colunas, syntax highlighting RUNIX Dark, histórico de execução e Biblioteca de Queries favoritas.

🔍

Schema Diff & Explain Plan

Compare bancos de dados lado a lado gerando scripts de sincronização e inspecione a árvore visual de custo de queries com EXPLAIN.

📊

Importação, Exportação & Gráficos

Exporte resultados para CSV, JSON, SQL e Excel (.xlsx), importe dados via assistente guiado e transforme resultados em gráficos instantaneamente.

🗂️

Conexões por Categoria

Organize suas conexões salvas em categorias personalizáveis (Produção, Staging, Local, Cliente) com filtro rápido na tela inicial.

✏️

Staging de Dados & Transações

Edite células diretamente na grade, adicione ou remova registros e revise o script SQL exato antes de aplicar o commit no banco.
